# Phase 5 · 系统性实机验收矩阵

前 4 个阶段的单点功能已逐项通过;Phase 5 是把它当成"日常做装工具"来用的
系统验收。每一节按顺序做,任何一条失败都记录:窗口档位、操作序列、
预期 vs 实际、终端输出、截图。

## 2. 快速点击手感(核心安全边界)

监控中在装备上快速连点改造:识别未决期间点击必须完全直通、无卡顿、
无丢失;只有严格命中后红窗才接管。与 .NET 1.0 对比手感应无差别。

## 3. 热键全链(游戏前台)

Ctrl⇧F10 开始(去抖后自动进入监控;若日志出现"稍后自动重试启动"
也应在 1 秒内成功)→ Ctrl⇧F12 停止 → Ctrl⇧F11 重新框选 →
Ctrl⇧F10 → 命中 → Ctrl⇧F12 解除 → Ctrl⇧F10 连续三轮。

## 4. DPI 与多屏

系统缩放 100%/125%/150% 各开一次:发丝线不消失、字不糊、
三档窗口尺寸正确;若有副屏,把窗口拖过去重复检查,框选跨屏一次。

## 5. 长时间稳定

挂机监控 30 分钟(画面基本不变):CPU/内存不持续增长
(任务管理器观察),浮动 ±,期间 unchanged 复用生效(判定耗时低);
结束后正常停止、关闭程序进程干净退出。

## 6. 三档与编辑回归

切档不丢输入;数值校验错误行出现/消失不推挤;保存反馈正确;
Dock 设为目标 → 规则台模板与归一化同步;树显示与设置一致。

## 已知边界(本轮不算失败)

- HUD 浮窗、识别截图、多词缀结构化编辑、游戏/语言切换控件未接。
- 「验证并保存」将在引入自动保存后与撤销一起精简(撤销本轮已移除)。
- 红窗样式沿用旧版配色,Ledger 重配色在收尾轮。
