# Rust 版后续工作计划

本文件用于在额度恢复后直接续接工作，避免重复做已经完成的迁移和长测。

## 当前可由用户实机验证的版本

- 功能主链已接通：实时监控、截图识别、单词缀、多词缀组合、数值条件、
  POE1/POE2、英文/繁中、红色命中提醒、声音、快捷键、状态浮窗和设置保存。
- 当前正式版本仍是 .NET 1.0；Rust 版保持独立预览设置目录，不覆盖正式配置。
- 用户本轮只需记录真实体验问题，不需要执行仓库里的批量基准。
- 2026-08-14 最新主题修补版位于
  `artifacts/rust-preview-dark-ui-fast-fix/POE-Alarm-Rust-Preview-0.1.0-win-x64.zip`，
  SHA-256 为 `65A123179A11248095C9DC93CA572213F6F139EFC3F1A6458FF6EB0AE4DECC88`。
  它修复词缀框 `Ctrl+A`、状态浮窗空白和高频整窗重绘，统一为所有语言在命中前鼠标
  完全直通、严格命中后才由红窗阻挡，并加入第一版深色原生主题。需要用户重点复测繁中
  连续点击、主窗/浮窗闪烁、暗色控件文字与命中后红窗。

建议每个问题记录：游戏版本、词缀语言、单词缀/多词缀、目标规则、实际装备文字、
是否使用截图识别、是否出现提醒，以及大致复现步骤。若方便，可附原始截图。

## 额度恢复后的优先顺序

1. **处理用户实机反馈**  
   先修复卡顿、漏报、误报、窗口遮挡、快速点击直通、命中后红窗和关闭异常；不以降低
   识别严格度换速度。快速模式不再恢复任何命中前鼠标闸门。

2. **完成原生界面重做**  
   保留 Rust/Win32 运行主链，以 Direct2D + DirectWrite 重做主窗口视觉层；继续使用原生
   输入控件保证中文输入法和键盘操作。界面按“监控、规则、识别区域、提醒、设置”拆页，
   高级诊断默认收起，不引入 GPUI、Tauri 或 WebView。

3. **PoEDB / PoE2DB 复合词缀闭环**  
   从 POE1 与 POE2 当前数据库各抽取真实装备词缀，覆盖 Any、All、AtLeast、重复物理
   词缀一对一、范围/至少/至多/精确数值、小数、负数、混合词缀和近邻负例。数据库文字
   只证明规则语义；OCR 结论必须另用真实游戏截图证明，二者不得混写。

4. **补齐仍缺的真实素材门禁**  
   - POE1 英文装备提示框：至少 2 张图、4 个正例、2 个语义近邻负例、2 个跨图负例。
   - 游戏自然产生的两行词缀：不得使用人工换行图代替；拿到素材后再跑 30–100 ms 瞬态回放。
   - 四种配置（POE1/2 × 英文/繁中）的连续实机监控与命中/非命中记录。

5. **正式替代与发布门槛**  
   在干净 Windows 环境验证最终 ZIP、配置接管与回滚；确认实机准确率、响应速度、关闭流程、
   多屏/DPI、快速点击无丢失和命中后红窗后，才把 Rust 设置目录和版本身份切换为正式版
   并退役 .NET。

## 明确不做

- 不恢复已删除的谨慎模式，除非先重新完成产品闭环与安全模型。
- 不通过放宽匹配、减少复核或伪造截图来获得更好成绩。
- 不把固定截图循环、人工换行或文本语料冒充真实游戏长期使用证据。
